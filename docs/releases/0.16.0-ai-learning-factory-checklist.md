# Nyra/Core 0.16 release checklist

## Scope and governance

- [x] Continue on `feature/nyra-ai-learning-factory-v0.16`.
- [x] Record Git and live-service rollback points.
- [x] Keep OAuth, Auth0, callback, issuer, audience, client IDs and secrets out
  of scope.
- [x] Keep provider/external execution disabled.
- [ ] Obtain an exact Core gate before push, PR, merge, configuration and deploy.

## Runtime and isolation

- [ ] Classify every Core and Nyra branch with complete exposure metadata.
- [ ] Verify every canonical client/audience pair server-side.
- [ ] Verify exact visible sets for ChatGPT, Codex, adjacent software and Admin
  Control Room.
- [ ] Verify `owner_root` ChatGPT cannot bypass vertical isolation.
- [ ] Verify direct routes cannot bypass registry/catalog filtering.
- [ ] Verify all payload branch overrides fail closed.
- [ ] Verify the MCP top-level surface remains exactly 13.

## Persistence and recovery

- [ ] Apply both v0.16 migrations to a real ephemeral PostgreSQL instance.
- [ ] Attest bounded runtime roles with `SET LOCAL ROLE`.
- [ ] Verify tenant isolation, CAS/idempotency, receipt replay and restart
  recovery.
- [ ] Disable the release using the rollback migration without deleting audit,
  trace or dataset metadata.
- [ ] Re-enable and verify the same records remain readable.

## Tests and benchmarks

- [ ] Unit, contract, isolation, injection, DTT and regression suites green.
- [ ] 240 integrated Learning Factory cases green.
- [ ] At least 95% branch-selection and tool-selection accuracy.
- [ ] 100 paired baseline-vs-optimized cases measured on the same snapshot and
  rubric.
- [ ] Actual provider usage distinguished from deterministic estimates.
- [ ] No savings claim unless provider usage and quality receipts are verified.
- [ ] Guardrail p95 overhead at or below 15%, or an explicit release veto.

## Release and live verification

- [ ] Versions, changelog, manifest, benchmark report and rollback runbook
  finalized.
- [ ] Draft PR opened on the existing branch and CI green.
- [ ] Independent supervisor approves the exact diff and evidence.
- [ ] Protected merge to `main`.
- [ ] Deploy only Universal Core and Core MCP if both remain modified.
- [ ] Verify exact live commit, health/readiness, filtered registry/catalog,
  scorecard and 13-tool surface.
- [ ] Perform and record rollback rehearsal.
